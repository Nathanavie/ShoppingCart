# ShoppingCart

A simple shopping cart built in React. Products load from a local JSON file, you add them to a cart, and the total is calculated with multi-buy deal pricing applied to some items. Cart quantities persist in localStorage so a page refresh keeps your basket.

## Stack

- React 16 (Create React App), class components
- Local JSON for product data, localStorage for persistence

## Running locally

```bash
npm install
npm start
```

Then open http://localhost:3000.
